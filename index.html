Informasi keamanan & penyimpanan

Versi GitHub Pages tidak mempunyai autentikasi Lark maupun database bersama. Jangan memasukkan password, token, data klien rahasia, atau dokumen internal sensitif ke dalam repositori publik. Perubahan editor hanya ada pada browser ini sampai JSON dipublikasikan ulang.

PANDUAN PENGGUNA

Bantuan & Panduan

Petunjuk mengoperasikan VIP Electronic Knowladge Base.

Memulai

  1. Buka menu Pusat Pengetahuan untuk melihat semua artikel.
  2. Ketik kata kunci di kolom pencarian; pilih kategori bila perlu.
  3. Klik artikel untuk membaca isi, lalu pilih Favorit untuk menyimpannya.
  4. Klik Tambah Artikel untuk membuat entri; gunakan Sunting untuk memperbarui isinya.
  5. Buka Pengaturan Data untuk mengekspor JSON sebagai cadangan atau mengimpor koleksi.

Memublikasikan perubahan kepada tim

Perubahan editor disimpan di browser. Untuk menerbitkan ke website yang dipakai bersama, ekspor JSON lalu perbarui file data/articles.json di repositori GitHub. Pengguna dengan perubahan lokal sebelumnya dapat memilih Pulihkan Data Bawaan untuk mengambil versi yang baru diterbitkan.

Menjalankan di Lark

Unggah berkas ke GitHub Pages, kemudian buat Custom App → Web app pada Lark Developer Console. Masukkan URL HTTPS website sebagai halaman utama desktop dan seluler. Dokumen selengkapnya ada di docs/PANDUAN_LARK.md.

Batasan

Tampilan di Lark tidak otomatis memberikan autentikasi, hak akses per pengguna, sinkronisasi multi-perangkat, atau perlindungan konten. Fitur tersebut memerlukan backend dan penyimpanan privat.
